# Waku G0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prova tecnica G0 di Waku: muro → porta → vano → undo → export IFC → stesse modifiche via CLI e MCP, su stack Rust nativo auditato.

**Architecture:** Workspace Cargo con soli crate G0. `domain` puro; `commands` è l'unico punto di mutazione (singolo writer, revisioni, undo a snapshot). Desktop possiede il modello; `waku-mcp` è un ponte stdio → named pipe verso il desktop; CLI headless su file con lock.

**Tech Stack:** Rust 1.100 (edition 2024), nalgebra, serde/serde_json, thiserror, uuid, zip (deflate puro Rust), clap, eframe/egui/egui-wgpu/wgpu, tokio, rmcp 3.x, cargo-deny.

**Spec:** `docs/superpowers/specs/2026-11-17-waku-g0-design.md` (PDR: `Waku_PDR_v2_2_Rust.md`)

## Global Constraints

- Solo Rust; niente runtime JS/Python/Rhai, niente kernel C/C++ (AC-16). Crate con `build.rs` nativo solo se in `docs/native-deps.md`.
- Coordinate dominio `f64` in mm, Z verticale; GPU `f32` rispetto a origine locale.
- Licenza Apache-2.0; cargo-deny allow-list: MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2-Clause, BSD-3-Clause, ISC, Unicode-3.0, Zlib, CC0-1.0. Altre licenze (OFL, MPL-2.0, Ubuntu-font) solo con eccezione motivata in `deny.toml`.
- Ogni mutazione passa da `CommandService`. Mesh = cache derivata, mai fonte per export.
- Nomi binari: `waku`, `waku-cli`, `waku-mcp`. Crate senza nome prodotto (`domain`, `commands`, …). Estensione `.waku`, URI `waku://`.
- IFC: schema `IFC4` (ADD2 TC1), sottoinsieme; nessuna dichiarazione di conformità MVD.
- Gate per ogni task: `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.

## Review Focus

1. Muro di lunghezza zero o spessore ≤ 0 inserito da qualunque canale → `CommandError::Invalid`, modello invariato (test in Task 3).
2. Apertura più larga del muro o che sborda dopo spostamento/accorciamento del muro → comando rifiutato, nessuna apertura orfana (Task 3).
3. Espressione con unità miste o garbage (`2 m + 30 cm`, `5/0`, `1e400`, `abc`) → risultato corretto o errore, mai panic/NaN (Task 2).
4. Disco pieno / errore durante save → file originale intatto (Task 6, simulato con writer che fallisce).
5. Richiesta MCP malformata o enorme (> 1 MiB) sul pipe → errore, desktop non crasha (Task 10).
